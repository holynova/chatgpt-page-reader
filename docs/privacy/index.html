最后更新：2026-11-10 · 适用版本：0.6.0

谁维护这款扩展

回答成书 · AI 分页阅读（版本 0.6.0）的 GitHub 维护者是 holynova。本政策说明扩展如何处理信息。本政策适用于扩展 0.6.0，说明为阅读功能处理信息的方式。

处理哪些信息、为什么处理

扩展仅在声明支持的 AI 网站读取已加载的回答、提问、Markdown、图片 URL、会话标题和链接，用于识别回答、提供阅读入口、生成目录、分页排版和恢复位置。点击“加载历史”时会沿用原页面的滚动和展开控件读取更多项目或会话。为响应翻页、焦点、目录、控件隐现和输入，扩展还会临时处理相应的键盘、指针、点击及滚动事件，不记录行为分析日志。扩展不读取所有网站的浏览历史。

正文、偏好和草稿存在哪里

正文、目录缓存、各轮阅读位置和未发送的书内草稿在当前页面内存中处理，不作为完整对话文件保存。字号、行宽、字体、主题等排版偏好通过 chrome.storage.local 保存在本机，不使用浏览器跨设备同步。当前 AI 网站的 sessionStorage 会临时保存目标会话路径、回答标识、阅读偏移和时间，以支持跳转恢复；超过约 20 秒的记录不再用于恢复，并在后续初始化时清理，不是定时删除承诺。

什么时候会向外部发送信息

扩展没有自己的服务端、账号系统、广告、分析统计或额外模型 API。开发者不会通过本扩展收到你的正文、会话目录或草稿。在 ChatGPT 内，只有你主动点击发送或按 Enter 提交书内追问时，扩展才把该问题交给 ChatGPT 的原生输入和发送流程，由该平台按你原有的账号及其政策处理。Gemini 和实验性 DeepSeek 适配不提供书内发送。正文图片仍使用其原始来源，重新展示图片可能触发浏览器图片请求；原文链接只在你点击后打开，资源来源网站的规则继续适用。

权限与访问范围

storage 用于本机排版偏好；activeTab 与 scripting 用于你点击工具栏图标时，在缺少脚本的当前支持页面中补注入包内脚本。内容脚本只匹配 chatgpt.com、chat.openai.com、gemini.google.com 和 chat.deepseek.com 的 HTTPS 页面。扩展不请求 cookies、history、身份认证、支付、位置、网络拦截或所有网站访问权限，不读取密码或认证 cookies。DeepSeek 尚未完成登录后的实站验证，属于实验适配。

用途与分享限制

处理数据仅用于你可见的阅读、排版、目录、进度和主动追问。不出售数据，不用于广告、跨站画像、信用评估、贷款或其他无关用途。扩展对用户数据的使用和传输遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。对话可能含你自己写入的个人或敏感信息；它们仍作为正文在本机处理，扩展不对其进行身份识别或画像。

保存期限、删除和你的控制

你可以退出阅读、关闭书内追问、停止历史加载，并在排版面板点击“重置”恢复默认偏好。页面内存随页面上下文结束而释放；卸载扩展可移除其扩展本地存储。临时跳转记录使用对应 AI 站点的 sessionStorage，浏览器恢复会话时可能恢复此类数据；如需明确清除，可使用浏览器清理该站点的网站数据，这可能同时影响该站点的登录状态。上述操作不会删除 AI 平台已经保存的对话，你需要在原平台管理这些内容。

安全与外部服务

扩展脚本全部随安装包提供，不从 CDN 或远程地址下载可执行代码。支持的网站仅匹配 HTTPS；扩展不自行代理或改变原文图片及链接的传输方式，也不保证用户设备或浏览器存储另有独立加密。请使用你信任的设备和浏览器。GitHub 仓库和问题反馈由 GitHub 提供；如果你主动反馈，GitHub 和维护者将看到你主动填写的内容，请不要在公开反馈中粘贴私密问答。

联系与政策更新

隐私问题、数据控制疑问和故障反馈可通过下方 GitHub Issues 链接联系维护者。不要在公开问题中填写敏感内容；如需私密沟通，可先仅提出联系请求。产品行为变化时会更新本政策及日期，必要时同步更新商店披露。
